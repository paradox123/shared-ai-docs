# DWT-S5 L3 Runtime Temp-Repo Delivery Pilot

## Why

The testsuite now has accepted L2 proof that parent-first orchestration, single-child delivery kickoff and closeout gates work with retained Promptfoo/Codex evidence. It still needs one controlled L3 pilot that exercises an actual delivery against a disposable runtime repository without touching or describing original repositories.

## What

- Define and implement a DWT-S5 L3 runner that materializes a synthetic temp repo from source-controlled fixtures.
- Validate current DWT-S5 handoff, Parent Child Index row, concrete write-set and retained DWT-S3 evidence before delivery starts.
- Run or honestly block local runtime and container/harness gates inside the generated temp repo.
- Reject stale handoffs, original-repo targets, credential copies, out-of-run-dir writes, blocked-runtime-as-pass evidence and descendant auto-release.
- Emit DWT-S4-compatible summary, telemetry, style and efficiency artifacts.

## Impact

- Adds the selected L3 runtime-temp-repo proof after accepted DWT-S3 closeout.
- Keeps KI-fuer-KMU original repositories read-only and unnamed as runtime targets.
- Preserves DWT-PR3, DWT-PR4 and DWT-PR5 through implementation and closeout.
