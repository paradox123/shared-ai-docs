# Design

This batch applies the proven link-only OpenSpec relationship pattern to the first part of the KI legacy v1 OpenSpec pool.

The selected changes represent the early runtime foundation and first parallel delivery slices:

1. `bootstrap-kickstart-foundation`
2. `spec-01-runner-hardening`
3. `spec-02-03-parallel-delivery`

All rows are mapped to existing Mittelstand KI Startbahn entities instead of becoming primary specs. This keeps the current v2 specs canonical while preserving legacy delivery evidence for traceability.
