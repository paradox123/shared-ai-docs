# Proposal

## Why

The previous OpenSpec audit proved that link-only OpenSpec relationship mapping works without polluting primary SpecOps dashboards. The RAG OpenSpec pool is the next cohesive group and is small enough to process as a larger batch.

## What Changes

1. Add RAG OpenSpec rows to the shared OpenSpec relationship audit.
2. Map the canonical `rag-cli-runtime` spec and both archived RAG OpenSpec changes to existing SpecOps RAG targets.
3. Update Control Spec, source inventory and backlog evidence from classified-only to relationship-audited for the RAG OpenSpec group.

## Impact

No runtime code or historical source documents are modified. This is a metadata/reference update for SpecOps traceability.
